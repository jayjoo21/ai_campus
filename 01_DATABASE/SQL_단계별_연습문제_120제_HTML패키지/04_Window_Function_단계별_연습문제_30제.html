기대 결과동점 구간에서 세 함수 결과가 다르게 보입니다.

작성 전에 생각할 것어느 테이블에서 시작하고 어떤 조건·그룹·순서를 적용할지 먼저 말로 정리합니다.
힌트 보기
사용 테이블: 없음 — 문제 안의 sample_payments CTE에서 샘플 데이터를 직접 생성합니다.
CTE로 동점이 보장된 5행을 만듭니다.
정답과 해설 보기
WITH sample_payments AS (
    SELECT 1 AS payment_id, 1002 AS customer_id, 500000 AS amount
    UNION ALL SELECT 2, 1002, 500000
    UNION ALL SELECT 3, 1002, 300000
    UNION ALL SELECT 4, 1002, 200000
    UNION ALL SELECT 5, 1002, 200000
)
SELECT payment_id, amount,
       ROW_NUMBER() OVER (ORDER BY amount DESC) AS row_number_rank,
       RANK() OVER (ORDER BY amount DESC) AS rank_value,
       DENSE_RANK() OVER (ORDER BY amount DESC) AS dense_rank_value
FROM sample_payments
ORDER BY amount DESC, payment_id;
해설
ROW_NUMBER는 고유번호, RANK는 동점 후 순위 건너뜀, DENSE_RANK는 연속순위입니다.

selected CTE와 customers를 customer_id로 N:1 JOIN합니다.
정답과 해설 보기
USE fintech_fraud_lab_class;
WITH candidates AS (
    SELECT la.application_id, la.customer_id, la.application_at,
           la.requested_amount, la.default_12m_label,
           br.report_id, br.report_date, br.external_credit_score,
           ROW_NUMBER() OVER (
               PARTITION BY la.application_id
               ORDER BY br.report_date DESC, br.report_id DESC
           ) AS rn
    FROM loan_applications AS la
    LEFT JOIN bureau_reports AS br
      ON la.customer_id = br.customer_id
     AND br.report_date <= DATE(la.application_at)
),
selected AS (
    SELECT *
    FROM candidates
    WHERE rn = 1
)
SELECT s.application_id, s.customer_id, s.application_at,
       s.requested_amount, s.external_credit_score,
       c.region, c.income_band, s.default_12m_label
FROM selected AS s
LEFT JOIN customers AS c
  ON s.customer_id = c.customer_id
ORDER BY s.application_at;

힌트 보기
사용 테이블: fintech_fraud_lab_class.loan_applications, fintech_fraud_lab_class.bureau_reports, fintech_fraud_lab_class.customers
loan_applications에서 먼저 approved = 1과 default_12m_label IS NOT NULL로 학습대상을 제한하고, Bureau 후보에 ROW_NUMBER()를 적용해 신청시점 이전 최신 1건을 선택합니다.
정답과 해설 보기
USE fintech_fraud_lab_class;
WITH bureau_candidates AS (
    SELECT la.application_id, la.customer_id, la.application_at,
           la.product_type, la.requested_amount, la.loan_purpose,
           la.annual_income, la.employment_years, la.debt_to_income,
           la.approved, la.default_12m_label,
           br.report_id, br.report_date, br.external_credit_score,
           br.credit_card_count, br.loan_count,
           br.delinquency_30d_count, br.delinquency_90d_count,
           br.inquiries_6m, br.revolving_balance, br.utilization_rate,
           ROW_NUMBER() OVER (
               PARTITION BY la.application_id
               ORDER BY br.report_date DESC, br.report_id DESC
           ) AS rn
    FROM loan_applications AS la
    LEFT JOIN bureau_reports AS br
      ON la.customer_id = br.customer_id
     AND br.report_date <= DATE(la.application_at)
    WHERE la.approved = 1
      AND la.default_12m_label IS NOT NULL
),
asof_bureau AS (
    SELECT *
    FROM bureau_candidates
    WHERE rn = 1
)
SELECT a.application_id, a.customer_id, a.application_at,
       a.product_type, a.requested_amount, a.loan_purpose,
       a.annual_income, a.employment_years, a.debt_to_income,
       c.region, c.income_band,
       a.external_credit_score, a.credit_card_count, a.loan_count,
       a.delinquency_30d_count, a.delinquency_90d_count,
       a.inquiries_6m, a.revolving_balance, a.utilization_rate,
       a.default_12m_label
FROM asof_bureau AS a
LEFT JOIN customers AS c
  ON a.customer_id = c.customer_id
ORDER BY a.application_at, a.application_id;
해설
CSS 부실예측 학습 데이터는 실제 대출 성과를 관찰할 수 있는 승인 신청을 기준으로 구성합니다. 따라서 approved = 1이고 default_12m_label IS NOT NULL인 신청만 남긴 뒤, 신청시점 이전 최신 Bureau 보고서 한 건을 선택해야 합니다.
