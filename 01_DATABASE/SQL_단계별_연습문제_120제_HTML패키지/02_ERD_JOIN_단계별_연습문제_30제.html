사용 테이블: fintech_fraud_lab_class.card_payments, fintech_fraud_lab_class.merchants, fintech_fraud_lab_class.devices, fintech_fraud_lab_class.customers
최종 JOIN 구조를 COUNT(*)와 COUNT(DISTINCT ...)로 감쌉니다.
정답과 해설 보기
USE fintech_fraud_lab_class;
SELECT COUNT(*) AS joined_rows,
       COUNT(DISTINCT cp.payment_id) AS distinct_payments
FROM card_payments AS cp
LEFT JOIN merchants AS m ON cp.merchant_id = m.merchant_id
LEFT JOIN devices AS d ON cp.device_id = d.device_id
LEFT JOIN customers AS c ON cp.customer_id = c.customer_id
WHERE cp.payment_at >= '2026-01-01'
  AND cp.payment_at <  '2026-08-01';
해설
프로젝트형 JOIN은 결과를 만든 뒤 Grain 검증까지 포함해야 완결됩니다.
