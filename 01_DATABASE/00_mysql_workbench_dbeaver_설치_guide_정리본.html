① MySQL Server
실제 데이터를 저장·처리하는 DB 엔진
② MySQL Workbench
Oracle/MySQL 공식 GUI 관리 도구
③ DBeaver

가장 중요한 개념: Workbench나 DBeaver만 설치한다고 MySQL 데이터베이스가 생기는 것은 아닙니다. MySQL Server가 먼저 설치되어 실행 중이어야 Workbench와 DBeaver가 접속할 수 있습니다.

이 강의안의 설치 순서

  1. MySQL Server 설치 → DB 엔진 실행
  2. MySQL Workbench 설치 → localhost:3306으로 접속 확인
  3. DBeaver Community 설치 → 같은 MySQL Server에 접속 확인

수업에서 MySQL 8.0.x를 사용하는 이유

이 강의안은 초보자가 같은 화면과 절차를 따라가기 쉽도록 MySQL Server 8.0.x를 기준으로 설명합니다. SQL의 기본 문법, 스키마·테이블 생성, JOIN, 인덱스, 트랜잭션 같은 핵심 학습 내용은 이 환경에서 충분히 실습할 수 있습니다.

설치 화면에서 같은 8.0 계열의 패치 번호가 조금 다르더라도 기본 설치 흐름과 접속 방식은 거의 같습니다. 수업에서는 서버 버전과 포트, 서비스 이름을 기록하고 모든 도구에서 같은 접속정보를 사용하는 것이 중요합니다.

패치 버전은 달라질 수 있습니다. 같은 MySQL 8.0 계열이라면 화면의 세부 버전 번호가 달라도 기본 SQL 실습 절차는 동일합니다.

설치 전 5분 준비

① Windows 관리자 권한
프로그램 설치와 Windows 서비스 등록에 필요합니다.
② 인터넷 연결
Web Installer와 DBeaver JDBC 드라이버 최초 다운로드에 필요합니다.
③ root 비밀번호 기록
설치 중 만드는 관리자 비밀번호를 반드시 기록합니다.
④ 기본 포트 확인
MySQL 기본 TCP 포트는 3306입니다.

3306 포트 사용 여부 확인

Windows 키를 누르고 cmd 또는 PowerShell을 실행한 뒤 입력합니다.

netstat -ano | findstr :3306

아무 것도 나오지 않으면 보통 3306 포트가 비어 있습니다. 결과가 나오면 다른 MySQL/MariaDB가 이미 사용 중일 수 있습니다.

수업용 접속정보 기본값
Host: 127.0.0.1
Port: 3306
User: root
Password: 설치 중 본인이 정한 값

1. MySQL Server 설치

실제 데이터베이스 엔진을 먼저 설치합니다.

MySQL Installer 공식 다운로드MySQL 8.0 Community Server
화면 이미지: 아래는 Oracle/MySQL 공식 문서의 실제 설치 화면입니다. 버전과 Windows 테마에 따라 버튼 위치나 버전 숫자는 조금 달라질 수 있습니다.

1MySQL Installer 다운로드

  1. 위의 MySQL Installer 공식 다운로드를 엽니다.
  2. Windows용 MySQL Installer 8.0 계열을 선택합니다.
  3. Web Installer는 파일이 작고 설치 중 인터넷으로 구성요소를 내려받습니다. 개인 PC에 적합합니다.
  4. Full/Offline Installer는 파일은 크지만 인터넷이 불안한 강의실에서 유리합니다.
  5. Oracle 계정 가입을 건너뛸 수 있는 No thanks, just start my download와 같은 링크가 보이면 이를 사용할 수 있습니다.
권장: 개인 PC = Web Installer / 교육장 대량 설치 = Full Installer.

2설치 프로그램 실행

  1. 다운로드한 .msi 파일을 더블클릭합니다.
  2. Windows UAC의 “이 앱이 디바이스를 변경하도록 허용하시겠습니까?”에서 예를 누릅니다.
  3. MySQL Installer가 열리면 제품 선택 단계로 이동합니다.

3설치할 제품 선택

Workbench는 다음 장에서 별도 설치하므로 Server만 먼저 설치하면 역할을 이해하기 쉽습니다.

  1. Server Only가 보이면 선택합니다.
  2. 또는 Custom → MySQL Servers → MySQL Server → 8.0 → x64를 추가합니다.
  3. Next를 누릅니다.
Developer Default가 보이는 설치 프로그램에서는 한 번에 여러 개발도구를 설치할 수도 있습니다. 본 강의에서는 역할 분리를 위해 Server를 먼저 설치합니다.

4Check Requirements 확인

Visual C++ Runtime 등 필요한 구성요소가 없으면 Installer가 요구사항을 보여줍니다.

  1. 미충족 항목을 확인합니다.
  2. 자동 설치가 가능하면 Execute를 누릅니다.
  3. 수동 설치가 필요한 항목은 안내된 구성요소 설치 후 다시 확인합니다.

5서버 파일 설치

  1. Installation 화면에서 Execute를 누릅니다.
  2. 상태가 Complete/성공 표시가 되면 Next.
  3. Product Configuration 단계로 들어갑니다.
여기까지는 프로그램 파일 설치이고, 이제 포트·비밀번호·Windows 서비스를 설정합니다.

6Type and Networking

항목수업용 권장값뜻
Config TypeDevelopment Computer 또는 Development개발용 PC에서 과도한 메모리 사용을 줄임
TCP/IP체크Workbench/DBeaver가 TCP로 접속
Port3306MySQL 기본 포트
X Protocol Port기본값 유지일반 SQL 수업에서는 수정 불필요
3306이 사용 중이면 3307 같은 다른 포트를 지정할 수 있습니다. 이후 Workbench와 DBeaver에도 같은 포트를 입력해야 합니다.
방화벽: 같은 PC의 localhost 접속만 하는 수업이라면 외부 네트워크에 MySQL 포트를 불필요하게 개방할 필요가 없습니다.

7Authentication — 기본값 유지

MySQL 8.0의 기본 보안 인증 방식을 권장합니다. 특별한 호환성 이유가 없다면 오래된 인증 방식으로 변경하지 않습니다.

초보자: 권장되는 Strong Password Encryption 선택을 유지하고 Next.

8root 비밀번호 만들기

root는 MySQL 최고 관리자 계정입니다.

  1. MySQL Root Password를 입력합니다.
  2. Repeat Password에 한 번 더 입력합니다.
  3. 비밀번호를 반드시 기록합니다.
  4. 첫 설치에서는 추가 사용자를 만들지 않아도 됩니다.
주의: 회사·은행·이메일에서 실제 사용하는 비밀번호를 수업용 DB에 재사용하지 마세요.

9Windows Service 설정

항목권장값
Configure MySQL Server as a Windows Service체크
Windows Service NameMySQL80 등 기본값 유지
Start the MySQL Server at System Startup보통 체크
Run Windows Service as기본 Standard System Account
의미: PC를 재부팅해도 MySQL 서비스가 자동으로 실행됩니다.

10Server File Permissions → Apply Configuration

Windows Service 다음에는 데이터 폴더 권한 화면이 나타날 수 있습니다. 개인 학습용 PC라면 일반적으로 첫 번째 권장 옵션을 그대로 사용합니다.

  1. Execute를 눌러 설정을 적용합니다.
  2. Writing configuration file, Starting the server, Applying security settings 등이 순서대로 처리됩니다.
  3. 각 항목이 성공하면 Finish.
성공 기준: Windows Service 등록과 서버 시작, 보안 설정 적용이 모두 성공해야 합니다.

2. MySQL Workbench 설치

Workbench는 Oracle/MySQL 공식 GUI입니다. SQL 작성, DB 관리, EER 모델링, .mwb 모델 파일 열기에 사용합니다.

MySQL Workbench 공식 다운로드Windows 공식 설치 문서
2026년 8월 기준 공식 다운로드 페이지의 Workbench 버전은 8.0.47입니다. Windows x64 MSI가 가장 간단합니다.

1Windows x64 MSI 다운로드

실행 오류가 나면: Workbench 공식 Windows 문서의 .NET Framework 및 Microsoft Visual C++ Redistributable 요구사항을 확인합니다.

3. DBeaver Community 설치

DBeaver는 MySQL뿐 아니라 PostgreSQL, Oracle, SQLite 등 여러 DB를 같은 방식으로 다루는 범용 GUI입니다.

DBeaver Community 공식 다운로드DBeaver 공식 설치 문서

자주 발생하는 오류와 해결법

1. Can't connect to MySQL server on 'localhost:3306'

원인: MySQL 서비스가 꺼져 있거나 포트가 다릅니다.

  1. Win+R → services.msc
  2. MySQL80 서비스가 실행 중인지 확인
  3. 설치 때 3307을 썼다면 GUI도 3307로 변경

2. Access denied for user 'root'@'localhost'

  • Username이 root인지 확인.
  • 저장된 비밀번호를 지우고 다시 입력.
  • root 비밀번호를 잊었다면 공식 비밀번호 재설정 절차 사용.

3. Port 3306 is already in use

netstat -ano | findstr :3306

PID가 보이면 다른 프로세스가 사용 중입니다. 기존 MySQL을 확인하거나 새 서버를 3307로 구성합니다.

4. 'mysql' is not recognized

Windows PATH에 MySQL bin 폴더가 없을 가능성이 큽니다.

"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p

5. Workbench DLL/런타임 오류

Microsoft Visual C++ Redistributable와 .NET Framework 요구사항을 확인합니다.

6. DBeaver Driver files 다운로드 실패

  • 인터넷 연결 확인
  • 회사/학교 프록시 확인
  • 다른 네트워크에서 최초 JDBC 드라이버 다운로드 후 재시도

7. Workbench는 되는데 DBeaver는 안 됨

서버는 정상일 가능성이 큽니다. DBeaver의 Host/Port/User/Password와 JDBC Driver 상태를 확인합니다.
