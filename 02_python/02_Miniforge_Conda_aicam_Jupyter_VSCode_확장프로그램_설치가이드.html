2. Miniforge 설치

Miniforge는 conda-forge를 기반으로 Python 가상환경과 패키지를 관리할 수 있는 가벼운 배포판입니다.

Miniforge GitHub 최신 릴리스 Windows x86_64 설치 파일 직접 다운로드 Miniforge GitHub 저장소
Windows 10/11 일반 PC: 대부분 Intel/AMD 64비트 환경이므로 Miniforge3-Windows-x86_64.exe를 받으면 됩니다. 위의 Windows x86_64 설치 파일 직접 다운로드 버튼을 누르면 GitHub의 최신 Windows 설치 파일을 바로 받을 수 있습니다.
  1. Miniforge GitHub 페이지에서 Windows installer 링크를 클릭합니다.
  2. 다운로드 폴더에서 Miniforge3-Windows-x86_64.exe 설치 파일을 실행합니다.
  3. 설치 마법사를 기본값으로 진행합니다.
  4. 설치 후 시작 메뉴에서 Miniforge Prompt를 실행합니다.
  5. 프롬프트 앞에 (base)가 보이는지 확인합니다.

설치 후 일반 Windows CMD에서도 conda 사용하기

Miniforge를 설치한 직후에는 Miniforge Prompt에서는 conda가 동작하지만, 일반 Windows CMD에서는 conda 명령을 찾지 못할 수 있습니다. 한 번만 초기화하면 이후 새로 여는 CMD에서도 conda를 사용할 수 있습니다.

처음 한 번만 설정: 시작 메뉴에서 Miniforge Prompt를 실행한 뒤 아래 명령을 입력합니다.
Miniforge Prompt에서 실행
conda init cmd.exe
  1. conda init cmd.exe 실행이 끝나면 Miniforge Prompt와 열려 있는 CMD 창을 모두 닫습니다.
  2. Windows에서 새 명령 프롬프트(CMD)를 실행합니다.
  3. 아래 명령으로 conda가 정상 인식되는지 확인합니다.
새 Windows CMD에서 확인
conda --version
conda env list
정상 상태: conda 버전과 환경 목록이 출력되면 일반 CMD에서도 설정이 완료된 것입니다. 이후 수업에서는 Miniforge Prompt를 꼭 사용할 필요 없이 일반 CMD에서 conda activate aicam을 실행할 수 있습니다.
aicam 환경 생성 후 일반 CMD에서 사용
conda activate aicam
python --version
주의: conda init cmd.exe 직후 이미 열려 있던 CMD에는 설정이 반영되지 않습니다. 반드시 CMD를 닫고 새로 실행하세요. 새 CMD에서도 conda를 찾지 못하면 Windows에서 로그아웃하거나 PC를 한 번 재시작한 뒤 다시 확인합니다.

3) Jupyter Server 설정 파일 생성

Notebook 7은 Jupyter Server 기반이므로 jupyter_server_config.py에 기본 작업 폴더와 포트를 지정합니다.

aicam 환경에서 설정 파일 생성
conda activate aicam
jupyter server --generate-config
설정 파일 위치
보통 C:\Users\사용자이름\.jupyter\jupyter_server_config.py가 생성됩니다. 이미 설정 파일이 존재하면 덮어쓸지 묻는 메시지가 나올 수 있습니다. 기존 설정을 유지해야 한다면 N을 선택하고 기존 파일을 그대로 VS Code로 열어 아래 설정만 추가·수정합니다.

4) code .으로 설정 파일 열기

설정 파일을 메모장으로 수정하지 않고, 앞 강의에서 설치한 VS Code를 code . 명령으로 실행해서 편집합니다.

.jupyter 폴더를 VS Code로 열기
cd /d %USERPROFILE%\.jupyter
code .
  1. VS Code 왼쪽 Explorer에서 jupyter_server_config.py를 클릭합니다.
  2. Ctrl+F로 c.ServerApp.root_dir를 검색합니다.
  3. 해당 줄의 앞쪽 #을 제거하고 아래 값으로 수정합니다.
  4. 같은 방법으로 c.ServerApp.port와 c.ServerApp.port_retries도 설정합니다.
  5. Ctrl+S로 저장합니다.
jupyter_server_config.py에 설정할 값
c.ServerApp.root_dir = r'C:\ai_campus'
c.ServerApp.port = 9999
c.ServerApp.port_retries = 0
왜 root_dir을 설정하나요?
이제 어느 폴더에서 jupyter notebook을 실행하더라도 Notebook 파일 탐색기의 시작 위치가 C:\ai_campus로 고정됩니다.
왜 9999 포트를 사용하나요?
수업에서는 Jupyter의 기본값 8888 대신 9999를 사용해, 이후 Docker·웹 서버·API 실습에서 자주 사용하는 8000·8080·8888 등의 포트와 구분하기 쉽게 합니다. 9999 역시 다른 프로그램이 이미 사용 중일 수 있으므로 아래 확인 절차를 함께 사용합니다.
port_retries = 0을 설정하는 이유
9999가 사용 중일 때 Jupyter가 자동으로 10000, 10001 같은 다른 포트로 이동하지 않고 즉시 오류를 보여 줍니다. 수업에서는 모든 학생이 동일한 localhost:9999를 사용하기 때문에 문제를 찾기 쉽습니다.

5) 설정이 적용되었는지 확인

설정값 확인
jupyter server --show-config | findstr /I "root_dir port"

출력에서 C:\ai_campus, 9999, port_retries = 0이 확인되면 됩니다.

7) 9999 포트가 사용 중이거나 Windows 예약 포트일 때

9999 포트를 사용 중인 프로세스 확인
netstat -ano | findstr :9999
Windows 제외 포트 범위 확인

9999를 사용할 수 없다면
설정 파일의 c.ServerApp.port = 9999를 9998, 10000 등 실제로 비어 있는 포트로 변경한 뒤 다시 실행합니다. 수업 전체에서 하나의 포트를 통일해서 사용하는 것이 좋습니다.

  1. File → Preferences → Settings를 엽니다.
  2. default formatter를 검색하고 Prettier - Code formatter를 선택합니다.
  3. format on save를 검색하고 Editor: Format On Save를 체크합니다.

7. VS Code와 aicam 환경 연결

Python 파일과 Notebook이 모두 같은 aicam 환경을 사용하도록 설정합니다.

Jupyter 커널 등록

Miniforge Prompt에서 실행
conda activate aicam
python -m ipykernel install --user --name aicam --display-name "Python (aicam)"

Python Interpreter 선택

  1. VS Code에서 Ctrl + Shift + P를 누릅니다.
  2. Python: Select Interpreter를 검색합니다.
  3. Python 3.11 (aicam) 환경을 선택합니다.

Jupyter Kernel 선택

  1. .ipynb 파일을 엽니다.
  2. 오른쪽 위 Select Kernel을 클릭합니다.
  3. Python Environments → Python (aicam)을 선택합니다.

현재 실행 Python 확인

Notebook 셀에서 실행
import sys
sys.executable
정상 결과
출력된 경로에 envs\aicam 또는 aicam이 포함되어 있으면 올바른 가상환경을 사용 중입니다.
